## Proyectos 

### <img src="https://raw.githubusercontent.com/RoyFarid/goni/main/goni_frontend/public/brand/logo_completo_goni.png" width="30" align="absmiddle"/> [GONI](https://goni.up.railway.app/) Generador de moldes de costura

Convierte medidas corporales en moldes de costura listos para usar: ingresas tus medidas, eliges la prenda, y el sistema calcula el patrón con fórmulas paramétricas de patronaje.

- Exportación a **PDF a escala 1:1**, dividido automáticamente en hojas para imprimir en casa
- Exportación a **DXF** para CAD industrial
- Ajustes de holgura, costura y tipo de tela
- Modo invitado — pruébalo sin crear cuenta
